# Day-6

### React Introduction
    React is a JavaScript library developed by Meta for building user interfaces, especially single-page applications. It is component-based, declarative, and uses a virtual DOM to efficiently update the UI.

#### Library vs Framework
    A library provides specific functionality, while a framework generally provides a more complete structure and controls more of the application's flow.

#### Installation & Setup
#### Folder Structure

#### JSX
    JSX stands for JavaScript XML.
    It allows me to write HTML-like syntax inside JavaScript.

#### Strict Mode
    StrictMode is a React development feature that helps identify potential problems in an application.

    "Strict Mode does not mean the application runs twice in production. These additional checks are development-oriented."

#### Fragment
    A Fragment allows me to return multiple elements without adding an unnecessary DOM element.

    "A Fragment lets me group multiple React elements without adding an extra DOM node."

#### Virtual DOM & Actual DOM
    Virtual DOM: In-memory representation of UI used during React's reconciliation process.

    Actual DOM: The real DOM maintained by the browser. 

    Reconciliation: React's process of comparing the new UI representation with the previous one and determining the necessary updates.
