# Day-2

### components
    Class Component
    Functional Component

    "A component is a reusable piece of UI in React. Class components are ES6 classes that extend React.Component and use methods like render() and componentDidMount(). Functional components are JavaScript functions that return JSX and use React Hooks such as useState and useEffect for state and lifecycle-related behavior. In modern React, functional components are generally preferred because they are simpler, more concise, and provide Hooks for managing state and side effects."

### React Element vs React Component
    A React Element is a plain JavaScript object that describes what React should render.

    A React Component is a reusable piece of UI that returns React elements.

### State vs Props
    Props (properties) are used to pass data from a parent component to a child component

    State is data that is managed and controlled by a component.
### Life Cycle Methods
    "React component lifecycle describes the stages a component goes through: mounting, updating, and unmounting. In class components, important lifecycle methods include componentDidMount() for post-mount operations, componentDidUpdate() for post-update operations, and componentWillUnmount() for cleanup. In modern React functional components, we generally use Hooks, especially useEffect(), to handle side effects and cleanup."
