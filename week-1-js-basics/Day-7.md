# Day-7

## map() & set()
### map()
    Map is a JavaScript data structure that stores data as key-value pairs.

#### Map methods
    set() → adds or updates a key-value pair.

    get() → retrieves the value.

    has() → checks whether a key exists.

    delete() → removes a key-value pair.

    clear() → removes everything.

    size → returns the number of entries.

### set()
    A Set is a JavaScript data structure that stores unique values. If I add the same value multiple times, it is stored only once.

#### Set methods
    add() → adds a value.

    has() → checks whether a value exists.

    delete() → removes a value.

    clear() → removes all values.

    size → returns the number of unique values.

## Local Storage and Session Storage
### local storage
    localStorage is a Web Storage API that allows me to store key-value data in the browser. The data remains available even after I close the browser or restart the computer, until I explicitly remove it or the browser clears it.

### session Storage
    sessionStorage is also a Web Storage API, but the data is maintained only for the current browser tab/session.
