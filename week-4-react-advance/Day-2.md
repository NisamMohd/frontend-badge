# Day-2

### useReducer()
    useReducer is a React Hook used to manage complex state logic. It is an alternative to useState, especially when multiple state transitions depend on different actions.

### Custom Hook
    "A custom hook is a reusable JavaScript function that starts with use and allows me to reuse stateful logic between multiple React components. It can use built-in hooks like useState, useEffect, useReducer, etc."

### useContext
    useContext is a React Hook used to access shared data from a Context without passing props manually through every level of the component tree. It helps solve prop drilling.
